# WordPress.com Developer Documentation

This repository is for managing issues, enhancements, and new documentation requests for the [WordPress.com developer documentation](https://developer.wordpress.com/docs/).

## Submitting Bugs and Requesting Enhancements

To request changes, report bugs, or request new docs, please [open a new issue](https://github.com/Automattic/dotcom-dev-docs/issues/new/choose) and use one of the following labels:

- **Bug:** For bugs with the existing documentation.
- **Enhancement:** For enhancements to the existing documentation.
- **New Doc:** For requesting a new documentation page.

There are also **[Category] Name** labels that you can apply to associate a ticket with a specific category in the developer documentation.

## Making Changes to the Docs

Currently, this repo does not house the documentation itself. This is managed through a WordPress instance. New docs and major changes should be drafted and reviewed in a Google Doc.
